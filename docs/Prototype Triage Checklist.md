
 🟢🟡🔴 Diagnose the Creature

## 🟢 ALIVE

The program:

-   Compiles
-   Runs
-   Has meaningful interaction
-   Has at least one working core feature

## 🟡 UNDEAD

The program:

-   Runs
-   Has structure
-   May have menus/classes
-   Still relies heavily on placeholders
-   Core functionality is incomplete

## 🔴 DECEASED

The program:

-   Does not compile or run reliably
-   Has little or no usable interaction
-   Has no functioning core feature yet
